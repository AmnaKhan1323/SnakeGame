# 🐍 Snake Game

A classic Snake game built with vanilla JavaScript — guide the snake to eat food, grow longer, and avoid colliding with itself.

## ✨ Features

- Keyboard-controlled snake movement
- Food spawning and score tracking
- Background music/sound effects
- Collision detection for game-over conditions

## 🧰 Tech Stack

JavaScript, HTML, CSS

## 🚀 Getting Started

```bash
git clone https://github.com/AmnaKhan1323/SnakeGame.git
cd SnakeGame
# Open index.html directly in your browser
```
